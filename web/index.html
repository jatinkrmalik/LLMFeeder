Feed your LLM clean Markdown from any page.

LLMFeeder turns messy webpages into structured Markdown and copies it in one click. Built for ChatGPT, Claude, Gemini, and anyone who needs context without the chrome.

#

        

      


      

        

          
From page to prompt in one motion.

          
Select the page, convert, paste into your model. No tab hopping. No hand-cleaning HTML.

        

        
      


      

        

          
Built for the paste that matters.

          
Everything that changes how you feed context to an LLM, nothing that doesn’t.

        

        
    
          
  • 
            Smart extraction
            Mozilla Readability pulls the article, not the nav chrome.
          
    • 
          
  • 
            Multi-tab batch
            Convert several tabs at once. Merge, or download a ZIP.
          
    • 
          
  • 
            Token awareness
            Live GPT-4 / Claude-style estimates with configurable limits.
          
    • 
          
  • 
            Tables that survive
            HTML tables become real Markdown pipes, empty cells included.
          
    • 
          
  • 
            Lazy chat scroll
            Optional auto-scroll for Gemini, ChatGPT, Claude threads.
          
    • 
          
  • 
            Keyboard first
            Alt+Shift+M copy · Alt+Shift+D download · Alt+Shift+Z ZIP.
          
    • 
          
  • 
            Links on demand
            Strip URLs when you need fewer tokens, keep them when you don’t.
          
    • 
          
  • 
            Metadata you control
            Template citations with title, URL, author, date, and more.
          
    •
